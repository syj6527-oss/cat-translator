# 🐱 Cat Translator

SillyTavern용 맞춤형 번역 확장 프로그램

현재 버전: **v1.4.1**

이 파일은 정식 배포판입니다. 실험실판을 함께 설치한 경우에는 두 확장을 동시에 활성화하지 마세요.

연결 프로필 또는 Gemini 직접 연결을 사용하는 스마트 번역기로, RP(롤플레이) 환경에 최적화된 번역을 제공합니다.

---

## ✨ 주요 기능

### 번역
- **수동/자동 번역** — 🐱 버튼 클릭 또는 자동 번역 모드 (입력/출력/둘 다)
- **대사 병기 번역** — 대사는 원문 유지 + 한국어 번역 병기, 지문은 한국어 통번역
- **양방향 번역** — 한↔영 / 한↔일 / 한↔중 자동 감지
- **벌크 번역** — 최근 N개 메시지 병렬 일괄 번역 (⚡ 버튼, 동시 2개 처리)
- **재번역** — 같은 메시지를 다른 표현으로 재번역, 번역 히스토리에서 선택 가능
- **원문 복구** — 되돌리기(↩) 버튼으로 원문 즉시 복구

### 원문/번역문 편집
- **ST 연필 ✏️** → 원문(영어) 편집 (SillyTavern 기본 동작)
- **🐟/🍖 버튼** → 번역문(한국어) 편집 모드 진입
- 번역문 수정 후 저장해도 영어 원문이 자동 보존됩니다
- 편집 취소 시 번역문이 자동으로 복원됩니다

### 대사 병기 모드
```
원문: He clenched his jaw. "I bought a mattress for you."
병기: 그는 이를 악물었다. "I bought a mattress for you. [널 위해 매트리스를 샀어.]"
```
- `""` 안의 대사 → 원문 유지 + `[한국어 번역]` 병기
- `""` 밖의 지문 → 한국어 통번역
- 한영 / 한일 / 한중 병기 지원

### 스마트 기능
- **IndexedDB 캐시** — 동일 문장 재번역 시 API 호출 없이 캐시 히트 (30일 보존)
- **사전 (Glossary)** — 고유명사/용어 사전 등록 (드래그로 즉시 등록 가능 🐾)
- **사전 삼중 안전망** — 원문 선치환 + 프롬프트 Glossary + 번역 결과 결정론적 보정
- **스마트 사전 필터** — 본문에 실제 존재하는 단어만 프롬프트에 전송 (오적용 방지)
- **문맥 번역** — 이전 메시지 + 화자 정보를 참조하여 캐릭터 말투 일관성 유지
- **번역 스타일** — 일반 / 소설 / 캐주얼 / 자연스러운 한국어 / 존댓말 / 반말 / 문어체 (7종)
- **정규식 인포박스 보존** — 정규식 확장의 트리거 패턴을 번역 시에도 유지
- **AI 생성모드 감지** — 번역 대신 RP 이어쓰기를 하는 비정상 출력 자동 차단
- **원문 오염 자동복구** — ST 내부 렌더링으로 원문이 변경되는 경우 자동 감지 및 복구

### 번역 품질
- **systemInstruction 분리** — 시스템 프롬프트가 번역 대상으로 오인되는 현상 방지
- **CONTENT FIDELITY 규칙** — 내용 추가/삭제 금지, 감정 강도 보존, 액션 디테일 유지
- **스타일별 few-shot 예시** — 각 번역 스타일에 실제 번역 전/후 예시 내장
- **바깥 응답 래퍼 자동 복원** — 비제미나이 모델이 `<Response>` 같은 전체 래퍼만 생략하면 API 재호출 없이 앱에서 복구

### 캐릭터별 설정
- **번역 프롬프트 프리셋** — 캐릭터별 번역 스타일/지시사항 저장 및 자동 로드
- **프리셋 연결(🔗)** — 캐릭터 전환 시 연결된 프리셋 자동 적용
- **전역 기본 설정 보호** — 프리셋이 기본 설정을 오염시키지 않음

### 테마
- 🐱 **고양이 모드** (Flash 모델) — 주황 글로우, 🐟 완료/편집 이모지
- 🐯 **호랑이 모드** (Pro 모델) — 금색 글로우, 🍖 완료/편집 이모지
- 모델 전환 시 자동 테마 변경

## 🚀 처음 설정하기

1. SillyTavern **연결 관리자**에서 번역용 프로필을 만든 뒤 `연결 프로필`에서 선택합니다.
2. 프로필을 선택했다면 아래 `API Key`와 `모델`은 비워두어도 됩니다.
3. 원하는 번역 옵션을 정하고 맨 아래 **설정 저장 및 적용**을 누릅니다.

### 연결 방식 — 둘 중 하나만 사용

| 설정 | 기능 |
|---|---|
| **연결 프로필 (권장)** | SillyTavern 연결 관리자에 저장된 프로필을 사용합니다. 선택한 프로필의 API 공급자·모델·연결 설정을 그대로 따릅니다. |
| **직접 연결 모드** | 연결 프로필 없이 Google Gemini API에 직접 연결합니다. 아래 `API Key`와 `모델`을 설정해야 합니다. |
| **API Key** | 직접 연결할 때만 사용합니다. [Google AI Studio](https://aistudio.google.com/apikey)에서 발급한 Gemini 키(보통 `AIza...`)를 입력합니다. |
| **모델** | 직접 연결할 때만 사용합니다. 번역에 사용할 Gemini 모델을 선택하며, 목록에 없으면 `직접 입력`을 사용합니다. |

> 연결 프로필과 API Key를 둘 다 설정하면 **연결 프로필이 우선**이며, 아래 API Key·모델은 사용되지 않습니다.
>
> API Key는 비밀번호와 같습니다. 다른 사람에게 보내거나 설정 화면이 보이는 스크린샷에 노출하지 마세요.

직접 연결 순서: `연결 프로필 → 직접 연결 모드` 선택 → `직접 연결 설정 (고급)` 열기 → API Key 붙여넣기 → 모델 선택 → 저장.

### 번역 설정 한눈에 보기

| 설정 | 기능 |
|---|---|
| **자동 번역** | `입력만`은 내가 쓴 문장, `출력만`은 AI 응답, `둘 다`는 양쪽을 자동 번역합니다. `꺼짐`에서는 🐱 버튼으로 수동 번역합니다. |
| **고속 번역 (모든 모델)** | Gemini·비제미나이 프로필과 직접 연결 모두 지원합니다. 문맥을 축약하고 통신·품질 보정을 합쳐 최대 2회 호출하며 사전·사용자 지침·짧은 대명사 참고 문맥은 유지합니다. 의미·성별·수치·맞춤법 보존을 지시하고, 목표 언어·심각한 누락·일부 이종 문자 혼입을 검사합니다. 맞춤법·성별·의역 오류 전체를 검출하거나 일정 속도를 보장하지는 않습니다. 기본값은 꺼짐입니다. |
| **입력 내부 번역** | 전송 전에 한국어를 선택한 전달 언어로 번역합니다. 화면에는 한국어를 유지하고 AI 컨텍스트에는 번역문만 저장합니다. |
| **AI 전달 언어** | 내부 번역에 사용할 언어입니다. English, Japanese, Chinese, German, Russian, French를 지원합니다. |
| **양방향 번역** | 현재 문장의 언어를 감지해 한↔영·한↔일·한↔중 방향을 자동으로 바꿉니다. |
| **목표 언어 (AI 기본)** | 일반 번역의 기본 도착 언어입니다. 양방향 번역이나 대사 병기를 켜면 해당 모드가 번역 방향을 정합니다. |
| **대사 병기** | 따옴표 안 대사는 `원문 [한국어]`, 따옴표 밖 지문은 한국어로 표시합니다. |
| **직역 병기** | 자연 번역 아래에 원문·직역을 접이식으로 덧붙입니다. 출력이 길어져 번역 시간이 늘 수 있습니다. |
| **스타일** | 일반, 자연스러운 한국어, 소설풍, 반말·존댓말 등 번역 문체를 정합니다. |
| **온도** | 표현의 변화 폭입니다. 기본 `0.3`을 권장하며, 높일수록 다양하지만 번역이 흔들릴 수 있습니다. |
| **토큰** | 한 번에 생성할 수 있는 최대 출력 길이입니다. 긴 글이 중간에 잘리면 늘립니다. |
| **문맥 범위** | 번역할 때 참고할 이전 메시지 수입니다. 높이면 말투 유지에 도움이 되지만 더 느리고 입력량이 늘어납니다. |
| **재번역 강도** | 같은 메시지를 다시 번역할 때 이전 결과와 얼마나 다른 표현을 시도할지 정합니다. |
| **원문 수정 후 동작** | ST의 ✏️ 버튼으로 영어 원문을 고친 뒤 알림만 표시할지, 자동 재번역할지, 기존 번역을 유지할지 정합니다. |

### 기타 설정과 버튼

| 설정 | 기능 |
|---|---|
| **채팅 파일 관리 미리보기** | 채팅 기록 팝업에 번역·언어 전환 버튼을 자동으로 추가합니다. |
| **미리보기 마크업 정리** | 채팅 미리보기에서 YAML·태그 같은 마크업을 숨깁니다. API를 호출하지 않아 비용이 들지 않습니다. |
| **통합 지시사항** | 서술과 대사 전체에 적용할 지시를 적습니다. 구버전 단일 추가 지시와 프롬프트는 이 칸으로 자동 이전됩니다. |
| **서술 지시사항** | 서술·묘사·행동·내면 문장에만 적용할 문체 지시를 적습니다. |
| **대사 지시사항** | 따옴표 안 대사에만 적용할 말투·호칭 지시를 적습니다. 명시한 지침은 문맥에서 추론한 말투보다 우선합니다. |
| **인풋 번역 프롬프트** | 입력창 번역에만 적용할 별도 지시입니다. 공통 지침과 함께 적용되며, 비워두면 대사·말투 지침을 사용합니다. |
| **프롬프트 기본 설정** | 드롭다운의 `기본 설정`을 선택하면 현재 캐릭터 연결을 해제하고 저장된 기본 통합·서술·대사 지침과 문체·온도를 즉시 복원합니다. 세 지침이 모두 비어 있어도 💾로 기본 설정을 저장할 수 있습니다. |
| **사전** | 고유명사를 `원문=번역어` 형식으로 한 줄에 하나씩 고정합니다. 예: `Ghost=고스트` |
| **아이콘 표시** | 입력창·메시지창의 번역 버튼을 모두 보이거나 한쪽만 숨깁니다. |
| **캐시 삭제** | 저장된 번역 결과를 지웁니다. 사전·설정을 바꿨는데 예전 번역이 계속 나오면 사용합니다. |
| **설정 초기화** | Cat Translator 설정을 기본값으로 되돌립니다. |
| **내보내기 / 가져오기** | 현재 설정을 JSON 파일로 백업하거나 복원합니다. API Key와 자격증명은 내보내기 파일에서 자동 제외됩니다. |
| **현재 채팅 오염 정리** | 화면 표시용 번역이 원문에 섞여 자동 재번역이 안 될 때 현재 채팅을 복구합니다. |
| **설정 저장 및 적용** | 현재 값을 저장하고 즉시 적용합니다. 첫 설정 후 반드시 한 번 누르세요. |

### 빠른 추천값

| 목적 | 권장값 |
|---|---|
| 기본 수동 번역 | 자동 번역 `꺼짐` · 목표 언어 `Korean` · 온도 `0.3` · 문맥 범위 `1` |
| 한영 대사 병기 | 대사 병기 `한영 병기` · 목표 언어는 자동 결정 |
| 자연스러운 한국어 | 스타일 `자연스러운 한국어` · 필요한 고유명사는 사전에 등록 |

대사 병기 사용 시 입력창의 한국어는 순수 영어로 번역되어 전송되고, AI의 영어 응답은 대사만 원문과 한국어가 함께 표시됩니다.

입력 내부 번역을 켜면 입력창의 한국어를 유지한 채 알림으로 진행 상태를 표시하고, 번역 완료 후 실리태번의 기본 전송 흐름으로 전달합니다. 일반 Enter는 글자 확정·줄바꿈으로만 동작하고, 실제 내부 번역 전송은 비행기 버튼으로 실행합니다. 실제 사용자 메시지가 생성되면 채팅 화면에는 작성한 한국어가 보이지만 AI는 선택한 전달 언어만 받습니다. 해당 사용자 메시지에서 ✏️는 한국어 원문을 수정하고, 🐟/🍖는 AI에게 저장된 전달문을 직접 수정합니다. ✏️ 편집을 취소하면 기존 전달문과 한국어 표시를 함께 복구합니다. 내부 번역 실패 시에는 한국어를 대신 보내지 않고 전송을 중단하며 원문을 입력창에 유지합니다.

## ⚠️ 참고 사항

- 대사 원문과 번역문은 앱이 자동 조립하며, 일부 슬롯이 어긋나도 가능한 병기를 우선 표시합니다
- 캐릭터 프로필/시스템 프롬프트는 **영어로 유지** 권장 (한국어 지시 시 AI 출력 언어 혼동 가능)
- 정규식 확장의 인포박스 트리거 패턴은 번역 시 보존됨
- 병기 모드 전환 시 캐시 키가 자동 분리되어 기존 캐시와 충돌 없음
- 번역된 메시지의 원문(영어)은 내부적으로 보존됩니다. 화면에 보이는 한국어는 표시용이며, AI에게는 영어 원문이 전달됩니다.

## v1.4.1 지연·캐시 안정화

- 고속 번역(내부 번역 포함): API 총 2회 이내, 개별 요청 90초·전체 요청 예산 180초. 일반 번역: 총 3회 이내, 개별 120초·전체 300초. 시간초과는 자동 재시도하지 않습니다.
- 연결 프로필에도 취소 신호를 전달하고, 직접 연결의 응답 본문 수신까지 시간제한을 유지합니다. 연결 서비스·서버가 취소를 무시하면 서버 처리는 계속될 수 있습니다.
- 캐시의 결과 수용 기준을 정리하고 실제 모델·주소·전송 문맥·내부 번역 정책을 구분합니다. 문맥별 결과를 서로 덮어쓰지 않습니다.
- 기존 번역 이력은 보존합니다. 캐시 키 보강으로 업데이트 직후 기존 자동 캐시는 한 번 다시 번역될 수 있습니다.
- 영구 저장을 사용할 수 없으면 현재 탭에서 메모리 캐시를 사용합니다. 이 임시 캐시는 새로고침하면 사라집니다.
- 화면 변경 시 해당 메시지 위주로 검사하고, 동일 메시지의 반복 언어 분석과 중복 감시를 줄였습니다.
- 내부 번역 보정에서도 압축 프롬프트를 유지합니다. 한국어 등으로 번역하며 글자 수가 자연스럽게 줄어드는 경우를 과도 축약으로 오인하는 조건도 보정했습니다.
- 전체 경과시간·API 누적시간·각 시도 대기를 로그에 기록합니다. 동시에 번역해도 로그의 원문과 응답을 섞지 않습니다.
- 단일 길이 수치·단위 오류와 명시적 단수 주어의 성별 반전 일부를 추가 검사합니다. 모든 의미·성별·맞춤법 오류를 검출하거나 실서비스 응답속도를 보장하지는 않습니다.
